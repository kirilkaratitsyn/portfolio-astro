Ihr Shopify-Theme passt fast, aber eben nur fast? Ein Button sitzt falsch, eine Information fehlt auf der Produktseite, oder eine Funktion gibt es nur als kostenpflichtige App. Dieser Artikel hilft bei der Entscheidung: Was Sie selbst im Editor lösen, wann Sie das Theme anpassen lassen sollten, was in Briefing und Angebot gehört und wie Sie die Arbeit vergeben, ohne Ihren Live-Shop zu gefährden.

## Erst prüfen: Was Sie im Editor selbst können

Unter **Onlineshop › Themes › Anpassen** steckt mehr, als viele denken:

- **Farben und Schriften** für den ganzen Shop, unter den Theme-Einstellungen.
- **Sections hinzufügen, verschieben und ausblenden**, auf der Startseite und auf jeder anderen Seite.
- **Texte, Bilder und Buttons** in jeder Section.
- **Eigene Vorlagen**, etwa eine zweite Produktvorlage für eine bestimmte Produktgruppe.
- **Menüs** unter Inhalte › Menüs, unabhängig vom Theme.
- **Dynamische Quellen**: Felder einer Section mit Metafeldern verbinden, damit jedes Produkt eigene Angaben zeigt.

Probieren Sie Änderungen in einer **Kopie Ihres Themes** aus (Themes › Aktionen › Duplizieren). Die Kopie ist unveröffentlicht, Ihre Kunden sehen sie nicht. Wenn sich Ihr Wunsch damit lösen lässt, brauchen Sie niemanden.

## Wann sich ein Entwickler lohnt

Der Editor zeigt nur die Einstellungen, die der Theme-Entwickler vorgesehen hat. Alles darüber hinaus heißt: Code im Theme ändern. Typische Fälle:

- **Eine Funktion, die das Theme nicht hat**, zum Beispiel ein „In den Warenkorb“-Button direkt bei ähnlichen Produkten.
- **Ein Layout, das die Section nicht hergibt**, etwa eine andere Anordnung auf der Produktseite am Smartphone.
- **Produktdaten, die strukturiert angezeigt werden sollen**: Tabellen, Inhaltsstoffe, Maße oder Downloads aus Metafeldern. Wie man solche Daten anlegt, steht in [Shopify Metafelder und Metaobjekte](/de/blog/shopify-metafelder-metaobjects).
- **Eine App ersetzen**, wenn das, was sie tut, auch sauber im Theme geht und dann keine monatliche Gebühr und keinen fremden Code mehr kostet.
- **Fehler im Theme**, die nach App-Wechseln oder alten Anpassungen auftreten.
- **Navigation und Orientierung**, etwa Breadcrumbs für verschachtelte Kollektionen.

## Das Briefing: drei Fragen

Ein gutes Briefing ist kurz. Es beantwortet drei Fragen:

1. **Was stört Sie, und wo genau?** Ein Screenshot mit Markierung sagt mehr als ein langer Text. Nennen Sie Seite und Gerät: „Produktseite am Handy“ ist ein anderer Auftrag als „Startseite am Desktop“.
2. **Wie soll es aussehen, wenn es fertig ist?** Ein Beispiel aus einem anderen Shop, eine Skizze oder ein Satz wie „Der Button soll ohne Scrollen sichtbar sein“.
3. **Was darf sich nicht ändern?** Das übrige Design, die Adressen der Seiten, laufende Apps oder Kampagnen.

Dazu der Name Ihres Themes (zu sehen unter Onlineshop › Themes) und die Apps, die etwas im Shop anzeigen. Mehr braucht ein Entwickler für eine erste Einschätzung nicht.

## Was ein gutes Angebot für eine Theme-Anpassung enthält

- **Jede Änderung in einem Satz.** Was wird gebaut, was ausdrücklich nicht.
- **Arbeit in einer unveröffentlichten Kopie.** Ihr Live-Shop verkauft unverändert weiter.
- **Eine Vorschau zum Prüfen**, auf Handy und Desktop, bevor etwas live geht.
- **Freigabe durch Sie.** Veröffentlicht wird erst nach Ihrer Bestätigung.
- **Sections mit Einstellungen, wo es geht.** Dann pflegen Sie Texte und Bilder danach selbst im Editor.
- **Eine Liste der geänderten Dateien.** Wichtig für spätere Theme-Updates, dazu gleich mehr.
- **Ein klarer Preis oder eine klare Preislogik.** Bei mir ist es ein Festpreis nach dem Briefing; wovon Preise allgemein abhängen, steht in [Shopify-Shop erstellen lassen: Wovon die Kosten abhängen](/de/blog/shopify-shop-erstellen-lassen-kosten).

**Theme-Updates gehören ins Gespräch.** Wenn Sie ein Theme aus dem Theme Store aktualisieren, übernimmt Shopify Ihre Einstellungen und Inhalte, aber keine Änderungen am Code. Angepasster Code muss danach erneut eingebaut werden. Ein gutes Angebot sagt, wie die Änderungen dokumentiert werden, damit das in überschaubarer Zeit geht.

## Warnzeichen

- **Jemand fragt nach Ihrem Passwort.** Für Entwickler gibt es einen eigenen Zugang, siehe unten.
- **Arbeit direkt im Live-Theme.** Ein Fehler ist dann sofort für Ihre Kunden sichtbar.
- **Keine Liste der Änderungen.** Dann weiß beim nächsten Theme-Update niemand, was neu eingebaut werden muss.
- **Für jede Kleinigkeit wieder der Entwickler.** Wenn Sie nach der Anpassung nicht einmal einen Text selbst ändern können, wurde fest im Code gebaut, wo eine Einstellung gereicht hätte.
- **Eine neue App für jede Aufgabe.** Manchmal ist eine App richtig. Aber jede weitere App kann Code ins Theme bringen, der den Shop bremst. Mehr dazu in [Shopify-Shop langsam? 7 Ursachen](/de/blog/slow-shopify-store).

## Zugang sicher geben

Sie müssen Ihr Passwort nicht weitergeben. Laut Shopify-Hilfe läuft der Zugang für Entwickler über Zugriffsanfragen („Collaborator“):

- Der Entwickler sendet über sein Partner-Konto eine Anfrage. Sie sehen sie in den Einstellungen im Bereich „Users“ (Benutzer) und prüfen die angefragten Berechtigungen. Shopify rät, nur die Berechtigungen zu vergeben, die für die Aufgabe nötig sind.
- Zusätzlich können Sie dort im Bereich Security einen vierstelligen Code erzeugen; der Entwickler muss ihn bei seiner Anfrage eingeben. Ein neuer Code macht alte ungültig.
- Sie können den Zugang jederzeit wieder entfernen. Zudem läuft er automatisch ab, wenn sich der Entwickler 90 Tage nicht eingeloggt hat.

Klären Sie vorab, welche Berechtigungen für die Theme-Arbeit wirklich nötig sind und wann der Zugang wieder entzogen wird.

## Nachher: Ergebnis prüfen

1. **Vorschau auf dem Handy öffnen.** Prüfen Sie genau die Seiten aus Ihrem Briefing, auf Handy und Desktop.
2. **Bis zur Kasse durchklicken.** Produkt in den Warenkorb, weiter zur Kasse. So sehen Sie, ob die Änderung nichts anderes beschädigt hat.
3. **Im Editor ausprobieren.** Lässt sich der neue Bereich selbst bearbeiten, ausblenden, mit einem anderen Text füllen?
4. **Änderungsliste ablegen.** Sie brauchen sie beim nächsten Theme-Update oder wenn später jemand anderes am Shop arbeitet.

Erst dann geben Sie frei.

## Anpassen oder ein neues Theme?

Wenn die Liste der Wünsche lang wird, lohnt sich die Frage, ob das alte Theme noch die richtige Grundlage ist. Ein neueres Theme kann vieles schon selbst, wofür das alte Apps und Sonderlösungen braucht. Ob Anpassen oder Wechseln mehr bringt, sieht man meist schnell, wenn man das Theme einmal von innen anschaut. Mehr dazu auf der Seite zum [Shopify-Redesign und Theme-Wechsel](/de/services/shopify-redesign).

## Ein Beispiel: Lineargent

[Lineargent](/de/projects/lineargent), eine Marke für Silberschmuck aus der Nähe von Barcelona, nutzt ein angepasstes Prestige-Theme mit Hunderten Produkten und einem externen Tool für die Suche. Statt alles auf einmal umzubauen, habe ich das Theme zuerst geprüft und die Fixes dann in sieben kleinen Meilensteinen umgesetzt, jeder klein genug, um ihn im Live-Shop zu prüfen. Dazu kamen ein „In den Warenkorb“-Button bei ähnlichen Produkten und Breadcrumbs, die zeigen, wo eine Kollektion im Katalog liegt. Die Zusammenarbeit läuft mit einem zweiten Auftrag weiter, so wie bei einer [Shopify-Betreuung](/de/services/shopify-betreuung).

## Häufige Fragen

**Freelancer oder Agentur für eine Theme-Anpassung?** Für einzelne Änderungen reicht oft eine Person, die Liquid schreibt. Welche Fragen Sie jedem Anbieter stellen sollten, steht in [Shopify-Freelancer oder Agentur](/de/blog/shopify-freelancer-oder-agentur). Ich bin selbst Freelancer, das sollten Sie beim Lesen wissen.

**Kann ich mein Theme danach weiter selbst im Editor bearbeiten?** Ja, wenn die Anpassungen als Sections und Einstellungen gebaut sind. So baue ich sie.

**Verkauft mein Shop weiter, während daran gearbeitet wird?** Ja. Gearbeitet wird in einer unveröffentlichten Kopie, live geht sie erst nach Ihrer Freigabe.

**Was passiert bei einem Theme-Update?** Einstellungen und Inhalte bleiben, Code-Änderungen müssen neu eingebaut werden. Wer sauber dokumentiert, macht das in überschaubarer Zeit.

**Was kostet eine Anpassung?** Das hängt davon ab, was sich ändern soll. Nach einem kurzen Briefing bekommen Sie einen Festpreis, bevor ich anfange.
