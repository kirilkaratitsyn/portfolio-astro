Ihr Shopify-Theme passt fast: Ein Button sitzt falsch, eine Information fehlt auf der Produktseite, oder eine Funktion gibt es nur als kostenpflichtige App. Vieles lösen Sie selbst im Editor. Für den Rest können Sie das Theme anpassen lassen, ohne Ihren Live-Shop zu gefährden.

## Erst prüfen: Was Sie im Editor selbst können

Unter **Onlineshop › Themes › Anpassen** ändern Sie ohne Code:

- **Farben und Schriften** für den ganzen Shop.
- **Sections**: hinzufügen, verschieben, ausblenden.
- **Texte, Bilder und Buttons** in jeder Section.
- **Eigene Vorlagen**, etwa eine zweite Produktvorlage für eine Produktgruppe.
- **Menüs** unter Inhalte › Menüs.
- **Dynamische Quellen**: Felder einer Section mit Metafeldern verbinden, damit jedes Produkt eigene Angaben zeigt.

Testen Sie in einer **Kopie Ihres Themes** (Themes › Aktionen › Duplizieren). Sie ist unveröffentlicht, Kunden sehen sie nicht. Reicht das, brauchen Sie niemanden.

## Wann sich ein Entwickler lohnt

Der Editor zeigt nur Einstellungen, die der Theme-Entwickler vorgesehen hat. Alles andere heißt: Code im Theme ändern. Typische Fälle:

- **Eine fehlende Funktion**, zum Beispiel ein „In den Warenkorb“-Button bei ähnlichen Produkten.
- **Ein anderes Layout**, etwa der Produktseite am Smartphone.
- **Strukturierte Produktdaten**: Tabellen, Inhaltsstoffe, Maße oder Downloads aus Metafeldern, siehe [Shopify Metafelder und Metaobjekte](/de/blog/shopify-metafelder-metaobjects).
- **Eine App ersetzen**, wenn ihre Funktion auch im Theme geht, ohne monatliche Gebühr und fremden Code.
- **Fehler im Theme** nach App-Wechseln oder alten Anpassungen.
- **Navigation**, etwa Breadcrumbs für verschachtelte Kollektionen.

## Das Briefing: drei Fragen

1. **Was stört Sie, und wo genau?** Ein Screenshot mit Markierung reicht. Nennen Sie Seite und Gerät, etwa „Produktseite am Handy“.
2. **Wie soll es fertig aussehen?** Ein Beispiel aus einem anderen Shop, eine Skizze oder ein Satz wie „Der Button soll ohne Scrollen sichtbar sein“.
3. **Was darf sich nicht ändern?** Das übrige Design, die Adressen der Seiten, laufende Apps oder Kampagnen.

Dazu der Name Ihres Themes (unter Onlineshop › Themes) und die Apps, die etwas im Shop anzeigen.

## Was ein gutes Angebot für eine Theme-Anpassung enthält

- **Jede Änderung in einem Satz**, auch was nicht gebaut wird.
- **Arbeit in einer unveröffentlichten Kopie.** Ihr Live-Shop verkauft unverändert weiter.
- **Vorschau und Freigabe.** Sie prüfen auf Handy und Desktop, veröffentlicht wird erst nach Ihrer Bestätigung.
- **Sections mit Einstellungen, wo es geht.** Dann pflegen Sie Texte und Bilder selbst im Editor.
- **Eine Liste der geänderten Dateien.** Bei einem Update aus dem Theme Store übernimmt Shopify Einstellungen und Inhalte, aber keine Änderungen am Code. Diese müssen danach neu eingebaut werden.
- **Ein klarer Preis oder eine klare Preislogik.** Bei mir ist es ein Festpreis nach dem Briefing. Wovon Preise abhängen: [Shopify-Shop erstellen lassen: Wovon die Kosten abhängen](/de/blog/shopify-shop-erstellen-lassen-kosten).

## Warnzeichen

- **Jemand fragt nach Ihrem Passwort.** Entwickler bekommen einen eigenen Zugang.
- **Arbeit direkt im Live-Theme.** Jeden Fehler sehen Ihre Kunden sofort.
- **Keine Liste der Änderungen.** Beim nächsten Theme-Update weiß niemand, was neu eingebaut werden muss.
- **Fest im Code gebaut, wo eine Einstellung gereicht hätte.** Dann brauchen Sie für jeden Text wieder den Entwickler.
- **Eine neue App für jede Aufgabe.** Jede App kann Code ins Theme bringen, der den Shop bremst, siehe [Shopify-Shop langsam? 7 Ursachen](/de/blog/slow-shopify-store).

## Zugang sicher geben

Laut Shopify-Hilfe läuft der Zugang für Entwickler über Zugriffsanfragen („Collaborator“), nicht über Ihr Passwort:

- Der Entwickler sendet die Anfrage über sein Partner-Konto. Sie sehen sie in den Einstellungen unter „Users“ (Benutzer) und prüfen die Berechtigungen. Shopify rät, nur die nötigen zu vergeben.
- Im Bereich Security können Sie einen vierstelligen Code erzeugen, den der Entwickler bei der Anfrage eingeben muss. Ein neuer Code macht alte ungültig.
- Sie können den Zugang jederzeit entfernen. Er läuft automatisch ab, wenn sich der Entwickler 90 Tage nicht eingeloggt hat.

## Nachher: Ergebnis prüfen

1. **Vorschau öffnen.** Prüfen Sie die Seiten aus dem Briefing auf Handy und Desktop.
2. **Bis zur Kasse durchklicken.** So sehen Sie, ob etwas anderes beschädigt wurde.
3. **Im Editor ausprobieren.** Lässt sich der neue Bereich bearbeiten und ausblenden?
4. **Änderungsliste ablegen** für das nächste Theme-Update.

Erst dann geben Sie frei.

## Anpassen oder ein neues Theme?

Wird die Wunschliste lang, ist das alte Theme vielleicht nicht mehr die richtige Grundlage. Ein neueres Theme kann vieles selbst, wofür das alte Apps und Sonderlösungen braucht. Mehr zum [Shopify-Redesign und Theme-Wechsel](/de/services/shopify-redesign).

## Ein Beispiel: Lineargent

[Lineargent](/de/projects/lineargent), eine Marke für Silberschmuck aus der Nähe von Barcelona, nutzt ein angepasstes Prestige-Theme mit Hunderten Produkten und einem externen Tool für die Suche. Ich habe das Theme in kleinen Schritten geändert, jeder klein genug, um ihn im Live-Shop zu prüfen. Dazu kamen Breadcrumbs, die zeigen, wo eine Kollektion im Katalog liegt, und die Behebung eines Google-Tag-Loaders, der 15 Sekunden zu spät kam. Die Zusammenarbeit läuft mit einem zweiten Auftrag weiter, wie bei einer [Shopify-Betreuung](/de/services/shopify-betreuung).

## Häufige Fragen

**Freelancer oder Agentur für eine Theme-Anpassung?** Für einzelne Änderungen reicht oft eine Person, die Liquid schreibt. Fragen für jeden Anbieter: [Shopify-Freelancer oder Agentur](/de/blog/shopify-freelancer-oder-agentur). Ich bin selbst Freelancer.

**Kann ich mein Theme danach weiter selbst im Editor bearbeiten?** Ja, wenn die Anpassungen als Sections und Einstellungen gebaut sind. So baue ich sie.

**Verkauft mein Shop weiter, während daran gearbeitet wird?** Ja. Die Kopie geht erst nach Ihrer Freigabe live.

**Was passiert bei einem Theme-Update?** Einstellungen und Inhalte bleiben, Code-Änderungen müssen neu eingebaut werden.

**Was kostet eine Anpassung?** Das hängt vom Umfang ab. Nach einem kurzen Briefing bekommen Sie einen Festpreis, bevor ich anfange.
