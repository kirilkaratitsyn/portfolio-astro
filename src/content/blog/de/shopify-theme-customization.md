Ihr Shopify-Theme passt fast, aber eben nur fast? Ein Button sitzt falsch, eine Information fehlt auf der Produktseite, oder eine Funktion gibt es nur als kostenpflichtige App. Bevor Sie jemanden beauftragen, lohnt sich ein Blick darauf, was Sie im Editor selbst erledigen können. Vieles geht ohne eine Zeile Code. Für den Rest braucht es jemanden, der Liquid schreibt.

## Was Sie im Theme-Editor selbst ändern können

Unter **Onlineshop › Themes › Anpassen** steckt mehr, als viele denken:

- **Farben und Schriften** für den ganzen Shop, unter den Theme-Einstellungen.
- **Sections hinzufügen, verschieben und ausblenden**, auf der Startseite und auf jeder anderen Seite.
- **Texte, Bilder und Buttons** in jeder Section.
- **Eigene Vorlagen**, etwa eine zweite Produktvorlage für eine bestimmte Produktgruppe.
- **Menüs** unter Inhalte › Menüs, unabhängig vom Theme.
- **Dynamische Quellen**: Felder einer Section mit Metafeldern verbinden, damit jedes Produkt eigene Angaben zeigt.

Probieren Sie Änderungen in einer **Kopie Ihres Themes** aus (Themes › Aktionen › Duplizieren). Die Kopie ist unveröffentlicht, Ihre Kunden sehen sie nicht, und Sie können sie über die Vorschau in Ruhe prüfen.

## Wann es Code braucht

Der Editor zeigt nur die Einstellungen, die der Theme-Entwickler vorgesehen hat. Alles darüber hinaus heißt: Code im Theme ändern. Typische Fälle:

- **Eine Funktion, die das Theme nicht hat**, zum Beispiel ein „In den Warenkorb“-Button direkt bei ähnlichen Produkten.
- **Ein Layout, das die Section nicht hergibt**, etwa eine andere Anordnung auf der Produktseite am Smartphone.
- **Produktdaten, die strukturiert angezeigt werden sollen**: Tabellen, Inhaltsstoffe, Maße oder Downloads aus Metafeldern.
- **Eine App ersetzen**, wenn das, was sie tut, auch sauber im Theme geht und dann keine monatliche Gebühr und keinen fremden Code mehr kostet.
- **Fehler im Theme**, die nach App-Wechseln oder alten Anpassungen auftreten.
- **Navigation und Orientierung**, etwa Breadcrumbs für verschachtelte Kollektionen.

## Worauf Sie vorher achten sollten

**Kein Passwort teilen.** Ein Entwickler bekommt Zugriff über eine Mitarbeiteranfrage in Shopify. Sie entscheiden, welche Bereiche er sieht, und können den Zugriff jederzeit wieder entziehen.

**Nie direkt im Live-Theme arbeiten lassen.** Jede Änderung gehört zuerst in eine unveröffentlichte Kopie. So läuft Ihr Shop unverändert weiter, bis Sie das Ergebnis gesehen und freigegeben haben.

**Theme-Updates im Blick behalten.** Wenn Sie ein Theme aus dem Theme Store aktualisieren, übernimmt Shopify Ihre Einstellungen und Inhalte, aber keine Änderungen am Code. Angepasster Code muss danach erneut eingebaut werden. Darum ist es wichtig, dass jede Änderung nachvollziehbar dokumentiert ist und so viel wie möglich als Section mit Einstellungen gebaut wird.

**Lieber als Section als fest im Code.** Eine gute Anpassung können Sie danach selbst im Editor pflegen: Text ändern, Bild tauschen, ausblenden. Wenn Sie für jede Kleinigkeit wieder einen Entwickler brauchen, ist etwas falsch gelaufen.

## Anpassen oder ein neues Theme?

Wenn die Liste der Wünsche lang wird, lohnt sich die Frage, ob das alte Theme noch die richtige Grundlage ist. Ein neueres Theme kann vieles schon selbst, wofür das alte Apps und Sonderlösungen braucht. Ob Anpassen oder Wechseln mehr bringt, sieht man meist schnell, wenn man das Theme einmal von innen anschaut. Mehr dazu auf der Seite zum [Shopify-Redesign und Theme-Wechsel](/de/services/shopify-redesign).

Und wenn Ihr Shop vor allem langsam ist: Die häufigsten Ursachen dafür stecken ebenfalls im Theme. Ich habe sie in [Shopify-Shop langsam? 7 Ursachen](/de/blog/slow-shopify-store) zusammengefasst.

## Ein Beispiel: Lineargent

[Lineargent](/de/projects/lineargent), eine Marke für Silberschmuck aus der Nähe von Barcelona, nutzt ein angepasstes Prestige-Theme mit Hunderten Produkten und einem externen Tool für die Suche. Statt alles auf einmal umzubauen, habe ich das Theme zuerst geprüft und die Fixes dann in sieben kleinen Meilensteinen umgesetzt, jeder klein genug, um ihn im Live-Shop zu prüfen. Dazu kamen ein „In den Warenkorb“-Button bei ähnlichen Produkten und Breadcrumbs, die zeigen, wo eine Kollektion im Katalog liegt.

## Häufige Fragen

**Kann ich mein Theme danach weiter selbst im Editor bearbeiten?** Ja, wenn die Anpassungen als Sections und Einstellungen gebaut sind. So baue ich sie.

**Verkauft mein Shop weiter, während daran gearbeitet wird?** Ja. Gearbeitet wird in einer unveröffentlichten Kopie, live geht sie erst nach Ihrer Freigabe.

**Was passiert bei einem Theme-Update?** Einstellungen und Inhalte bleiben, Code-Änderungen müssen neu eingebaut werden. Wer sauber dokumentiert, macht das in überschaubarer Zeit.

**Was kostet eine Anpassung?** Das hängt davon ab, was sich ändern soll. Nach einem kurzen Briefing bekommen Sie einen Festpreis, bevor ich anfange.
